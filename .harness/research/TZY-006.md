## Architectural Analysis & Limitations
- **External Research**: Live external browsing tools are unavailable in this environment; all analysis is based on the local codebase structure and hexagonal architecture constraints.
- **Issue Identified**: The source code detector reported that Application Service `src/Application/Service/CouponService.php` had no corresponding class reference in `tests/*.php`.
- **Service Contract**:
  - `CouponService::listAll(): array` retrieves all coupon records via `CouponRepositoryPort::findAll()`.
  - `CouponService::create(string $name, string $code): int` trims `$name`, normalizes `$code` to uppercase and trimmed format, defaults `isActive` to `true`, and persists via `CouponRepositoryPort::save()`.

## Solution
- Added `tests/coupon_service_test.php` with substantive unit assertions and SQLite adapter integration checks.
- Verified:
  - Empty list retrieval on initialization.
  - Normalization of name trimming and code capitalization.
  - Setting `isActive` to `true` and `id` to `null` before persistence.
  - Returning the generated integer ID.
  - Multiple records listing and retrieval.
  - Integration with `SqliteCouponRepository` when SQLite PDO is available.
- Verified zero regressions and compliant with Hexagonal Architecture rules.
