# Research report: TZY-336 — image dimensions in admin media library

Date researched: 2026-11-09

## Question

Does the image in `src/Presentation/Views/admin/media/index.php` need intrinsic `width` and `height` attributes to reserve its layout space, and can accurate intrinsic dimensions be supplied from the current media model?

## Findings and effect on the feature

- MDN's `<img>` reference recommends supplying `width` and `height` matching the intrinsic dimensions so the browser can derive an aspect ratio before image data loads. This supports adding attributes when those actual dimensions are available; it does not support guessing arbitrary values. Source: https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/img (accessed 2026-11-09).
- MDN's aspect-ratio guide explains that CSS `width` and `height` can size replaced elements and that a fixed ratio can reserve the element's box. Source: https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Box_sizing/Aspect_ratios (accessed 2026-11-09).
- Repository inspection found the target image inside `.wp-media-thumb`. `public/assets/css/admin.css` already sets `.wp-media-thumb img` to `width: 100%`, `height: 140px`, and `object-fit: cover`. The grid establishes each thumbnail's width, while the explicit 140px image height reserves its vertical space before the resource loads. The rendering intentionally uses a fixed cropped thumbnail, not the source's uncropped intrinsic ratio.
- The media entity/repository currently retain file path, MIME type, and byte size, but no pixel dimensions. No deployed upload files were available in `public/uploads` to measure. Therefore intrinsic dimensions cannot be added accurately from current persisted data without expanding upload, persistence, and migration behavior. Adding guessed attributes (for example, `200x140`) could describe a false ratio and would be redundant with the CSS sizing already in effect.

## Decision

Keep the production markup and thumbnail CSS unchanged because the existing layout reserves the thumbnail box. Add focused regression coverage that the rendered media image remains in the thumbnail container and the stylesheet continues to declare its responsive width, fixed height, and crop behavior. Do not claim this proves or measures runtime CLS/Core Web Vitals; it verifies the intended reservation mechanism in the repository.
